## About

I work across the path from an ML or LLM prototype to a deployable, observable service: building AI/ML pipelines, automating cloud infrastructure, and connecting model capabilities to operational workflows. Recent projects include LLM-powered document retrieval, agent-assisted incident investigation, and multi-stage Databricks delivery.

I am also exploring world models, robotics, and Physical AI. These are active areas of curiosity and experimentation, not claims of established production expertise.
